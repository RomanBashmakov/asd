## Встроенное ПО СВР-Маршрутизатора

IL-114 Video Server (STM32 MCU Part)

ПО встроенного контроллера STM32, на котором организованы прием/передача пакетов ARINC-429 (в частности - получение даты/времени от авиационного хронометра ХАЭ-21), а также обмен по USART с собстевнно сервером информацией о статусах модулей всей системы - камер, сервера, накопителя.

## Генерация кода
ПРОЕКТ РАЗРАБОТАН В СРЕДЕ CubeIDE

В случае изменения .ioc файла, STM32CubeIDE запросит повторную генерацию кода. Разрешите ее.
По завершении генерации, удалите созданные файлы ./Core/Inc/main.h и ./Core/Src/main.c.
В файлах stm32f0xx_it.c и stm32f0xx_hal_msp.c замените подключение файла main.h на _Main.h

## Установка
- Соберите проект
- Соедините ПК и Контроллер СКД при помощи программатора
- Подайте питание на Контроллер СКД
- Нажмите кнопку Run
